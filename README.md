# TVM Finance Calculator

A web-based Time Value of Money (TVM) Finance Calculator developed for **BS3210 Assignment 1**.

The application provides multiple financial calculators in a simple and responsive dashboard.

## Features

The application includes:

1. Future Value Calculator
2. Present Value Calculator
3. Simple Interest Calculator
4. Compound Interest Calculator
5. EMI Calculator
6. Loan Amortization Schedule
7. Interest Rate Scenario Analysis

### Scenario Analysis

The scenario calculator compares EMI values for:

- 8%
- 10%
- 12%
- 15%

## Technology Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

No backend or database is required.
